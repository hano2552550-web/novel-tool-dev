# 小説 整形・校正ツール

Notionで書いた小説を、**Notionで見えているとおりの改行のまま**pixivなどに貼り付けるためのツールです。
あわせて、三点リーダーや句読点など、小説の表記ルールに沿っていない箇所をチェックできます。

👉 **ツールを開く：https://hano2552550-web.github.io/novel-tool/**

- 無料・登録不要。ブラウザで開くだけで使えます。
- **本文は外部に一切送信されません。** 処理はすべて、お使いのパソコンのブラウザの中で行われます。
- 個人が作成した**非公式**のツールです（[ご利用にあたって](#ご利用にあたって非公式免責事項)）。
- 更新の内容は [更新履歴（CHANGELOG）](CHANGELOG.md) をご覧ください。

---

## こんなことに困っていませんか？

Notionからコピーした本文をpixivに貼ると、**すべての行のあいだに空行が入って1行おき**になってしまいます。
しかも、場面転換のために入れた空行は、逆に消えてしまいます。

![Notion・そのまま貼った場合・ツールを通した場合の比較](images/00-problem.png)

このツールを通すと、Notionで書いた状態がそのまま再現されます。

## 使い方

### 1. ツールを開く

[ツールのページ](https://hano2552550-web.github.io/novel-tool/)を開きます（パソコンの **Chrome** または **Edge** がおすすめです）。

![ツールを開いたところ](images/01-start.png)

### 2. Notionからコピーして貼り付ける

Notionで本文を選択してコピー（`Ctrl+C` / Macは `⌘+C`）し、ツールの大きな入力欄に貼り付けます（`Ctrl+V` / `⌘+V`）。
画面上部に「貼り付けました！」と出て、「Notionの改行・空行をそのまま再現して貼り付けました」と表示されれば成功です。

![貼り付けたところ](images/02-pasted.png)

> 貼り付けたあとは、入力欄の中で直接文章を直すこともできます。

### 3. 校正チェック（必要なときだけ）

「🔍 校正チェック」を押すと、右側に気になる箇所の一覧が出ます。

![校正チェックの結果](images/03-check.png)

- 指摘をクリックすると、本文の該当箇所が選択されます。
- 「→」のボタンを押すと、その箇所だけ修正されます。
- **要確認**は直したほうがよいもの、**参考**は意図的ならそのままでよいものです。

### 4. まとめて直す

「✨ 安全な修正をまとめて適用」を押すと、機械的に直して問題ない箇所（`・・・`→`……`、`。」`→`」` など）を一度に直します。

![まとめて修正したところ](images/05-fixall.png)

間違えても「↩ 元に戻す」で元の状態に戻せます。

### 5. pixiv用にコピーして投稿

「📋 pixiv用にコピー」を押して、pixivの投稿画面に貼り付ければ完了です。

### 実行結果のお知らせ

ボタンを押すと、画面上部に結果が表示されます。

![成功したとき](images/10-popup-success.png)

うまくいかなかったときは、**原因**と**対処法**が表示されます。

![エラーのとき](images/11-popup-error.png)

## チェックできる項目

| 項目 | 例 |
|---|---|
| 閉じ括弧の直前の句点・読点 | `「です。」` → `「です」` |
| 「！」「？」の後の全角スペース | `本当？嘘だ` → `本当？　嘘だ` |
| 「！」「？」の後の句読点 | `！。` → `！` |
| 半角の「!」「?」 | `!` → `！` |
| 三点リーダーの表記と個数 | `・・・` `...` `…` → `……` |
| ダッシュの表記 | `—` `─` → `――` |
| 句読点の重複 | `、、` `。、` |
| 助詞の重複（打ち間違い） | `をを` `のの` |
| 言葉のくり返し | 「ただただかわいい。ただそれに…」の「ただ」など、同じ文・隣の文での重複 |
| 誤用・誤変換 | `的を得る` → `的を射る`、`見ずらい` → `見づらい`、`こんにちわ` → `こんにちは` など |
| 重ね言葉 | `頭痛が痛い` `後で後悔` `違和感を感じる` など |
| 同じ文末の連続 | 地の文で「〜いた。」が3文以上続く など |
| 作品メモの名前の打ち間違い | `ひかりり`（登録名「ひかり」）、ひらがな／カタカナ違い |
| さ入れ言葉 | `読まさせる` → `読ませる` |
| い抜き言葉（地の文） | `知ってる` → `知っている` |
| 文体の混在 | だ・である調の地の文に、です・ます調が混じっている |
| 二重否定 | `〜ないわけではない` など |
| 「〜たり」の片方だけ | `歌ったり踊る` → `歌ったり踊ったりする` |
| 「の」の連続 | `東京の駅の前の店` |
| 冗長な表現 | `することができる` → `できる` など |
| 段落の書き出しの重複 | 「彼女は」で始まる段落が3回以上続く など |
| 指示語（こそあど）の多用 | 1文に「これ・それ・あの」などが3つ以上 |
| 全角・半角の混在、機種依存文字 | `ABC` と `ＡＢＣ`、`①` `㈱` など |
| カタカナ語の表記ゆれ | `コンピューター` と `コンピュータ` |
| ひらがなにするのが一般的な漢字 | `〜して下さい` → `〜してください`、`する事` → `すること` |
| 読点の多すぎ・なさすぎ | 1文に読点5つ以上、70字以上で読点なし |
| ら抜き言葉 | `見れる` → `見られる` |
| 括弧の閉じ忘れ | `「` が閉じていない |
| 字下げの不統一、鉤括弧の行の字下げ | |
| 表記ゆれ | `出来る` と `できる` の混在 など |
| 半角カタカナ、日本語の間の半角スペース | |
| 長すぎる一文（120字超） | |

### 詳細チェック（辞書を使う校正）

項目名が「【詳細】」で始まるものは、日本語の辞書で文章を単語に分けてから判定する、より細かいチェックです。

![詳細チェックの結果](images/14-deep.png)

| 項目 | 例 |
|---|---|
| 言葉の重なり | `表情にででる`、`かわいいい`、`そのとおりり` |
| 同じ助詞・助動詞の連続 | `あいつがが` |
| 助詞の重なり | `私は彼は` |
| 日本語に混じった英字（変換ミス） | `行こうkと思った` |
| 読みが同じ言葉の表記ゆれ | `出来る／できる`、`言葉／ことば`、`心／こころ` |
| 辞書にないひらがなの言葉 | 打ち間違いの可能性がある言葉 |

- 初回だけ、辞書（約18MB）の読み込みに数秒かかります。2回目以降は速くなります。
- 辞書はこのツールと同じ場所から読み込みます。**本文はどこにも送信されません**（解析もお使いのパソコンの中で行います）。
- オフライン版（ダウンロードした `index.html` をダブルクリックで開いた場合）では、ブラウザの制限により詳細チェックは使えません。それ以外のチェックは使えます。

> 文脈を読まないと判断できない誤変換（「以上／異常」など）や、文としての不自然さは、ツールのルールでは見つけきれません。そうした箇所は「🤖 AI校正用にコピー」でAIにも確認してもらうのがおすすめです。

チェックする項目は、右側の「チェック項目の選択」でオン・オフを切り替えられます（設定はブラウザに保存されます）。

![チェック項目の選択](images/07-rules.png)

## 作品メモ（キャラ名・用語・世界観）

作品ごとに、登場人物の名前・呼び方・用語・世界観をメモしておけます。
メモを使うと、校正の精度が上がります。

![作品メモ](images/08-memo.png)

1. 「作品メモ」を開いて「＋ 新しいメモ」を押し、原作名やシリーズ名を付けます。
2. 「ひな形を入れる」を押すと書き方の例が入るので、自分の作品に合わせて書き換えます（「🗑 クリア」で内容を消せます。直後ならCtrl+Zで元に戻せます）。
   - `【人物】` `【用語】`：名前や用語を「、」で区切って並べます。（　）の中は自由なメモです。
   - `【言い換え】`：`よく間違える表記→正しい表記` の形で書きます。
   - `【世界観】`：自由に書けます。
3. 校正チェックをすると、**登録した名前の表記ゆれ・打ち間違い**（ひらがな／カタカナ違い、`ひかりり` のような文字の重なりなど）と、**言い換えで決めた言葉**を指摘します。

![作品メモを使った校正チェック](images/09-memo-check.png)

4. 「AI校正用にコピー」を押すと、メモも依頼文に添えられます。AIが名前を誤字と勘違いしにくくなり、呼び方の矛盾などにも気づきやすくなります。

### 自分だけのチェック項目を追加する

作品メモに `【チェック】言葉（説明）` と書くと、その言葉を校正チェックで指摘します。口ぐせや、使いすぎたくない言い回しの確認に便利です。
`【チェック】/正規表現/（説明）` のように `/` で囲むと、正規表現でも指定できます。

### 別の作品でも同じ設定を使う

- 「💾 .txtで書き出す」で、メモをテキストファイルとして保存できます。
- 同じ原作の別の作品を書くときや、別のパソコン・ブラウザで使うときは、「📂 .txtを読み込む」でそのまま読み込めます。
- 書き出したファイルは普通のテキストなので、メモ帳などで直接編集することもできます。

> メモはお使いのブラウザの中にだけ保存され、外部には送られません。ブラウザのデータを消すとメモも消えるので、大事なメモは書き出して保存しておくと安心です。

## 文章の分析

「📊 文章の分析」を押すと、右側に本文の統計が表示されます。

![文章の分析](images/13-stats.png)

- 文字数・行数・文の数・台詞の割合
- 1文の平均の長さ、長い文の数、文の長さの分布（いちばん長い文をクリックすると、その文に移動します）
- 漢字・ひらがな・カタカナの割合
- 地の文の文末の種類（「〜た。」ばかりになっていないかの確認）
- よく使っている言葉（同じ言葉の使いすぎの確認）
- 指示語・「という」・「こと」の数
- 章（`[chapter:…]`）ごとの文字数

## 整形の設定

ツール上部の「整形の設定」で、貼り付け時の動きを変えられます。

![整形の設定](images/06-settings.png)

- **改行の扱い**：普段は「自動」のままで大丈夫です。Notion以外から貼り付けて1行おきになるときは「空行を半分に詰める」を試してください。
- **地の文の字下げ**：行頭に全角スペースを付ける／外すを一括で行えます（「」で始まる台詞の行には付けません）。
- **連続する空行の上限**：空行が続きすぎるのを防ぎます。

## pixivの作品をNotionに戻す

pixivに投稿した作品を、改行・空行を保ったままNotionに取り込めます。

1. pixivで作品の**閲覧ページ**を開き、本文を選択してコピーします（Ctrl+C）。
2. ツールの入力欄に貼り付けます。「改行・空行をそのまま再現して貼り付けました」と出れば成功です。
3. 「📝 **Notion用にコピー**」を押し、Notionのページに貼り付けます。**1行が1ブロック、空行が空のブロック**として再現されます（字下げもそのまま残ります）。

- 章見出し（pixivの `[chapter:…]`）は、Notionの**見出し**ブロックになります。逆にNotionの見出しブロックは、pixiv用にコピーするときに `[chapter:…]` になります。
- ルビは pixivの記法 `[[rb:漢字 > かんじ]]` のまま残るので、もう一度pixivに投稿するときもそのまま使えます。
- 改ページ（`[newpage]`）のある作品は、閲覧ページが分かれているので、ページごとにコピーしてください。

## 仕上げはAIで誤字脱字チェック

このツールの校正チェックは、決まった形の誤りを見つける**一次チェック**です。
「根本／根元」のような文脈しだいの変換ミスや、文法・文のつながりの誤りは、ルールでは見つけきれません。仕上げにAIで確認するのがおすすめです。

![AI校正の案内と行へ移動](images/12-ai-flow.png)

1. 「🤖 AI校正用にコピー」を押します。誤字脱字・変換ミス・文法ミスを優先して探す依頼文と、**行番号つきの本文**（作品メモを使っていればメモも）がまとめてコピーされます。
2. ClaudeなどのAIに貼り付けて送ります。指摘が「行・該当箇所・修正案・種類・理由」の表で返ってきます。
3. 指摘の「行」の数字を、ツール右側の「**行へ移動**」に入れて Enter を押すと、その行が選択されます。そのまま直してください。

> ⚠️ AIに貼り付けた時点で、本文はそのAIサービスに送られます（ツール内のチェックは外部に送られません）。
> 性的な描写などを含む本文は、AIサービスによっては校正を断られる場合があります。

## ネットにつながずに使う（オフライン版）

ツールは `index.html` というファイル1つでできています。このファイルをパソコンに保存しておけば、**インターネットにつながっていなくても、詳細チェック（辞書を使う校正）以外の機能がすべて使えます**。詳細チェックは、ブラウザの制限により、ファイルをダブルクリックで開いた場合は使えません。

### 1. ファイルを保存する（最初の1回だけネットが必要）

1. このページの上部にあるファイル一覧から `index.html` をクリックします。
2. 右上の「⬇」（Download raw file）ボタンを押します。
3. `index.html` がダウンロードフォルダに保存されます。わかりやすい場所（デスクトップなど）に移しておくと便利です。ファイル名は変えても構いません（例：`小説整形ツール.html`）。

### 2. 開いて使う

保存したファイルをダブルクリックすると、ブラウザ（Chrome・Edge推奨）でツールが開きます。使い方はWeb版と同じです。

### 3. 本当に通信していないか確かめたいとき（任意）

ケーブルを抜いたりWi-Fiを切ったりしなくても、Chromeの機能でそのタブだけをオフラインにして試せます。

1. ツールを開いたタブで **F12** キーを押し、開発者ツールを開きます。
2. 上部の「**ネットワーク**（Network）」タブを選びます。
3. 「スロットリングなし（No throttling）」のプルダウンを「**オフライン**（Offline）」に変えます。
4. この状態で、貼り付け・校正チェック・コピー・作品メモの書き出しなどを試します。

「ネットワーク」タブの一覧に通信が増えないことからも、外部に何も送っていないことが確かめられます（Web版では、詳細チェック用の辞書ファイルをこのサイトから読み込む通信だけが表示されます）。開発者ツールを閉じると、オフラインの設定は元に戻ります。

### 注意点

- **作品メモと設定は、Web版とオフライン版で別々に保存されます。** ブラウザが「別のページ」として扱うためです。Web版で書いたメモをオフライン版で使うときは、Web版で「💾 .txtで書き出す」→オフライン版で「📂 .txtを読み込む」で移してください。
- **ツールが更新されても、保存したファイルは自動では新しくなりません。** 新しい機能を使いたいときは、1の手順でもう一度ダウンロードしてください（オフライン版どうしでは、作品メモと設定は引き継がれます）。
- 「🤖 AI校正用にコピー」は、コピーまではオフラインでもできます。貼り付け先のAIを使うときにはネットが必要です。

## よくある質問

**Q. 本文がどこかに送られたり、保存されたりしませんか？**
A. されません。このツールは本文を外部に送る通信ができないように設定されており、本文はお使いのブラウザの中だけで処理されます（通信するのは、詳細チェック用の辞書をこのサイトから読み込むときだけです）。ブラウザに保存されるのは、チェック項目のオン・オフなどの設定と作品メモだけで、本文は保存されません。

**Q. ネットにつながっていなくても使えますか？**
A. 使えます。[index.html](index.html) を保存しておけば、ダブルクリックで開くだけで、詳細チェック以外の機能がオフラインでも使えます。手順は「[ネットにつながずに使う（オフライン版）](#ネットにつながずに使うオフライン版)」をご覧ください。

**Q. 何文字まで使えますか？**
A. 文字数の上限はありません。30万字程度でも、校正チェック（詳細チェックを含む）は数秒で終わります（パソコンの性能によって変わります）。6万字を超える本文では動作を軽くするため、直したあとの自動再チェックを止めています（「🔍 校正チェック」を押せば更新されます）。なお、AIに貼り付ける場合は、AIサービス側の文字数の上限に注意してください。長い作品は章ごとに分けると確実です。

**Q. Notionからpixivへの貼り付けで、Notionの空行が再現されません。**
A. Chrome または Edge で開いてください。ほかのブラウザでは、Notionの空行の情報を受け取れないことがあります。

**Q. スマホでも使えますか？**
A. 画面は表示できますが、Notionからのコピー＆貼り付けはパソコンでのご利用をおすすめします。

**Q. pixiv以外（ぷらいべったーなど）でも使えますか？**
A. 使えます。「pixiv用にコピー」は普通のテキストとしてコピーするだけなので、ほかのサイトにも貼り付けられます。
